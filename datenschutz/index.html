Recipe Roulette

Was beim Aufruf der Seite passiert

  1. Der Browser lädt das Skript Puter.js von den Servern von Puter.
  2. Beim Anzeigen der Rezepte ruft der Browser Daten von TheMealDB ab.
  3. Bei jedem dieser Schritte wird technisch bedingt deine IP-Adresse an den jeweiligen Anbieter übertragen.
Da die kostenlose Version der Puter API angewendet wird,
wird nach einer Anmeldung mit einem Puter Konto gefragt.
Recipe Roulette ist nicht damit assoziiert und samelt somit auch keine Daten durch die Anmeldung.
